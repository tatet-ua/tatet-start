# Хостинг менторства — подготовка и ошибки

## Коннектор

- Claude (приложение и claude.ai): «Настройки → Коннекторы → Добавить свой коннектор» → название `tatet.mentor`,
  адрес `https://mentor.tatet.app/mcp` → «Подключить» → вход через Tatet Auth.
- Claude Code в терминале: `claude mcp add --transport http --callback-port 33418 tatet.mentor https://mentor.tatet.app/mcp`,
  затем в сессии `/mcp` → `tatet.mentor` → Authenticate. Без `--callback-port 33418` вход отклоняется. Точная
  команда есть и на странице ссылки от ментора.
- Вход проходит, а `me` отвечает отказом — почта студента не совпадает с почтой в карточке аккаунта у ментора.

## Лимиты аккаунта

5 сайтов, 256 МБ памяти и 0,5 CPU на сайт, 10 выкладок в час, одна база Postgres на аккаунт (256 МБ, наружу
закрыта). Точные значения — в ответе `me`.

## Сборка

| Проект | `build_pack` | Что указать |
|---|---|---|
| готовый HTML/CSS/JS или собранная статика (Vite, Astro в режиме static) | `static` | `publish_directory` (например `/dist`); если нужна сборка — `build_command` |
| Node, Python, Go и др. со стандартным `package.json` / `requirements.txt` | `railpack` | `port`; при необходимости `build_command`, `start_command` |
| то же, если railpack не справился | `nixpacks` | как у railpack |
| свой `Dockerfile` | `dockerfile` | `dockerfile_location`, `port` |

Приложение в монорепозитории — `base_directory` (например `/apps/web`). Проверка живости — `health_check_path`
(например `/health`), если у приложения есть такой адрес.

Приложение обязано слушать `0.0.0.0`, а не `localhost`, и тот порт, что указан в `site_create`. Nuxt и Nitro —
`HOST=0.0.0.0`, `PORT=<порт>` в переменных сайта или в команде запуска.

## Что не пройдёт

docker-compose, подключение дисков, свои сети Docker, выбор сервера и свои метки Traefik. Посредник пропускает только
поля из списка `site_create`, остальное вернёт в `dropped`. Файлы, которые приложение пишет на диск, пропадают при
каждой выкладке: всё, что нужно хранить, — в базу.

## Ошибки выкладки

| Что видно | Причина | Что делать |
|---|---|---|
| `site_status` долго без контейнера, логи пусты | не было `site_deploy` или сборка ещё идёт | вызвать `site_deploy` один раз, подождать, смотреть `site_status` |
| `exited:unhealthy`, в логах ошибка запуска | команда запуска, порт или нехватка переменной | исправить, push (сайт выложится сам) |
| контейнер работает, адрес отдаёт 502/504 | приложение слушает `localhost` или другой порт | `0.0.0.0` и порт из `site_create` |
| в логах `out of memory`, `Killed` | приложение не помещается в 256 МБ | уменьшить потребление; лимит меняет только ментор |
| push не выложил сайт | вебхук не добавлен (вторая команда `gh` не выполнена) | выполнить её, проверить `gh api repos/<owner>/<repo>/hooks` |
| сборка не может склонировать репозиторий | не добавлен ключ доступа (первая команда `gh`) | выполнить её |
| отказ «лимит выкладок» | 10 выкладок за час | подождать; `site_status` показывает, сколько осталось |
| `site_create` — имя занято | адрес `<name>-<студент>.tatet.app` уже занят | другое имя |
