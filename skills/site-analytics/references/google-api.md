# Доступ к статистике по API — команды и скрипты

Скрипты лежат в папке скила: `<папка скила>/scripts/`. Папку скила агент знает из строки «Base directory» при
загрузке скила. Пакеты: `pip install google-auth requests`. На Windows вывод с кириллицей —
`PYTHONIOENCODING=utf-8`.

## Пути в интерфейсах Google

Интерфейс бывает на русском или английском — названия даны на том языке, на котором обычно открывается.

- **GA4, ресурс:** `analytics.google.com` → «Администратор» → «Создать» → аккаунт, затем ресурс: часовой пояс,
  валюта, отрасль, цели. Передачу данных в продукты Google не включать.
- **GA4, поток:** ресурс → «Потоки данных» → «Веб» → `https://<домен>` → код `G-…`. Номер ресурса (цифры) —
  «Администратор → Сведения о ресурсе».
- **GA4, доступ сервисному аккаунту:** «Администратор → Управление доступом к ресурсу → + → Добавить
  пользователей» → почта → роль «Читатель», уведомление по почте снять.
- **Search Console, ресурс:** `search.google.com/search-console` → «Добавить ресурс» → тип «Домен» → `<домен>` →
  TXT-запись → «Подтвердить».
- **Search Console, доступ:** ресурс `sc-domain:<домен>` → «Настройки → Пользователи и разрешения → Добавить
  пользователя» → почта → «Ограниченный».
- **Google Cloud:** `console.cloud.google.com` → новый проект → «APIs & Services → Library» → Google Analytics Data
  API и Google Search Console API → Enable, проверка в «Enabled APIs & services» → «IAM & Admin → Service accounts →
  Create» (имя `analytics`, без ролей) → аккаунт → «Keys → Add key → Create new key → JSON».
- **Отозвать ключ:** «Service accounts → analytics → Keys» → удалить ключ, затем выпустить новый.

## Переменные `.env` папки аналитики

| Переменная | Что это | Откуда |
|---|---|---|
| `GOOGLE_SA_CLIENT_EMAIL` | почта сервисного аккаунта `analytics@<проект GCP>.iam.gserviceaccount.com` | JSON ключа, поле `client_email` |
| `GOOGLE_SA_PRIVATE_KEY` | закрытый ключ, одной строкой в кавычках, переводы строк — `\n` | JSON ключа, поле `private_key` |
| `GA4_PROPERTY_ID` | номер ресурса GA4, только цифры | GA4 → «Администратор → Сведения о ресурсе» |
| `GA4_MEASUREMENT_ID` | код потока `G-…`, для счётчика на сайте | GA4 → «Потоки данных» |
| `GSC_SITE_URL` | `sc-domain:<домен>` | ресурс типа «Домен» из шага 2 |

`.env` и `secrets/` — в `.gitignore` (скрипт переноса допишет сам, если их там нет).

## Перенос ключа в `.env`

После «да» студента браузер скачал файл `<проект GCP>-xxxxxxxx.json` в «Загрузки». Факт скачивания на Windows
проверять `Get-ChildItem`, а не `ls ~/Downloads`. Сам файл не открывать инструментом чтения.

```bash
python "<папка скила>/scripts/sa_to_env.py" "<путь к json>" "<папка аналитики>/.env" --property <номер ресурса> --domain <домен>
```

Скрипт пишет четыре переменные, переносит JSON в `<папка аналитики>/secrets/` и печатает только почту сервисного
аккаунта: её студент выдаёт в GA4 и Search Console.

## Проверка доступа

```bash
python "<папка скила>/scripts/check_google.py" "<папка аналитики>/.env"
```

Ожидается две строки:
- `GA4: OK, ресурс …, за 7 дней сессий N, пользователей M` — нули до установки счётчика — норма;
- `GSC: OK, sc-domain:<домен>, права siteRestrictedUser` (или `siteFullUser`).

Что значат ошибки:

| Ответ | Причина | Что делать |
|---|---|---|
| GA4 403 `SERVICE_DISABLED` | Analytics Data API не включён в `<проект GCP>` | включить, проверить в списке включённых, подождать пару минут |
| GA4 403 `PERMISSION_DENIED` | студент не выдал «Читателя» на ресурс или выдал на другой ресурс | сверить номер ресурса и почту в «Управлении доступом» |
| GSC 403 `SERVICE_DISABLED` | Search Console API не включён | как выше |
| `GSC: … нет в списке ресурсов` | доступ не выдан или ресурс заведён как `https://<домен>/`, а не «Домен» | выдать доступ; при другом типе ресурса вписать точное значение из списка в `GSC_SITE_URL` |
| `Unable to load PEM file` | в ключе `\\n` вместо `\n` | заново прогнать `sa_to_env.py` |
| `invalid_grant` | ключ удалён в Google Cloud или часы машины сбиты | выпустить новый ключ, сверить время |

## Отчёт реального времени (шаг 4)

Открыть `https://<домен>` в браузере (не на localhost и не на `*.tatet.app`), пройти пару страниц, затем:

```bash
python "<папка скила>/scripts/check_google.py" "<папка аналитики>/.env" --realtime
```

Строка `GA4 realtime: OK, активных пользователей за 30 минут N`, N ≥ 1. Ноль — сначала проверить, что в браузере
уходит `g/collect` с нужным `tid=G-…`; блокировщик рекламы в браузере тоже даёт ноль.
