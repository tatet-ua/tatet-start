# tatet-start

## Що це
Спосіб роботи з Claude Code від менторства Tatet: знання накопичуються поза чатом, велика робота ділиться між
агентами з технічними межами, «готово» підтверджується доказом.
Для студентів менторства з будь-якої сфери: тексти і SEO, ігри, сайти, інше. Програмувати не обов'язково.

## Потрібно
Claude Code, Python 3.10+ (команда `python` у терміналі), git.

## Встановлення
```bash
claude plugin marketplace add tatet-ua/tatet-start
claude plugin install tatet-start@tatet-start
python "<шлях до плагіна>/scripts/setup.py"
```

Шлях до плагіна: Claude Code тримає плагіни в
`~/.claude/plugins/cache/tatet-start/tatet-start/<версія>/`, де `~` — твоя домашня папка.
Установник питає одне — букву диска (на macOS і Linux — підтвердити `~/project`). Після нього з'являться
`<диск>:/project/DevOps` (склад ключів), `<диск>:/project/llm-wiki` (база знань) і команда `board`.
Якщо щось треба зробити руками, установник напише це в кінці. Потім перезапусти термінал.

## Перший день
1. Відкрий термінал у папці свого проєкту (або створи нову в `<диск>:/project/`) і запусти `claude`.
2. Скажи, що збираєшся зробити сьогодні, і працюй як завжди. Агент сам прочитає базу і запропонує крок.
3. Наприкінці скажи «завершуємо». Лог сесії і запис у базу з'являться самі.

Правило першого дня: своя справжня задача (стаття, рівень гри, сторінка сайту, лист), а не навчальна.
Нічого не налаштовувати і не вибирати інструменти.

## Що ти побачиш
На великій задачі сесія сама перейде в агентний режим. Першим рядком — позначка `*→ агентний режим: …*`, далі
«як я зрозумів» (об'єкт роботи, джерело правди, перевірка, незворотне) і таблиця агентів
«задача · тип · модель · чому · рубіж». Не згоден — напиши, що змінити; `#сам` — працювати без агентів,
`#агенти` — увімкнути режим самому. Незворотне (публікація, відправка, деплой, оплата) агент робить тільки
після твого «ок».

## Ключі
Усі ключі й токени — у `<диск>:/project/DevOps/.env`. Значення читають скрипти, модель не бачить значень.
Вписуй ключі у файл руками і ніколи не встав їх у чат. Папку `DevOps` не перейменовуй: захист знаходить її за назвою.

## Другий крок, через кілька тижнів
Дошка проєкту зі шляхом: старт, спринти, фініш, туман. Сервер дошки — команда `board serve`,
сторінка — http://127.0.0.1:8790. Решту команд підкаже агент за словами «дошка проєкту» або «шлях проєкту».

## Одне правило
Нове в набір і на робоче місце додається, коли вперлися в конкретну проблему, а не щоб «почати правильно».
Перший місяць — без сторонніх скілів і плагінів поверх набору. Іноді людині не потрібен новий скіл: їй
потрібно перестати покращувати робоче місце і нарешті зробити роботу.

## Оновлення
```bash
claude plugin marketplace update tatet-start
claude plugin update tatet-start@tatet-start
python "<шлях до плагіна>/scripts/setup.py"
```

Після оновлення в шляху до плагіна інша `<версія>`; установник переписує команду `board` під неї.

## Видалення
`claude plugin uninstall tatet-start@tatet-start`. Руками прибрати: обгортку `board` у `~/.local/bin`, чотири змінні
(`TATET_WIKI`, `TATET_DEVOPS`, `BOARD_DIR`, `BOARD_PORT`) у `env` файлу `~/.claude/settings.json` і блок між мітками
`tatet-start` у `~/.claude/CLAUDE.md`. Папки `project/llm-wiki` і `project/DevOps` — твої дані, їх ніхто не видаляє.

## Якщо ти вже проходив курс
Став так само. Свої нотатки й документи поклади файлами в `llm-wiki/raw/docs/`, потім у сесії скажи «проковтни»
і назви файл (скіл `kb-ingest`), по одному. Установник не перезаписує наявні файли й папки, а в `~/.claude/CLAUDE.md`
лише дописує свій блок між мітками. Папка `project` в іншому місці — `--root <шлях>` до setup.py.
